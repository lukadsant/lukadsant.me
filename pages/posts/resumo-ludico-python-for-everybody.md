## Introdução

Este texto não foi feito para ser lido como um resumo passivo. A ideia aqui é ensinar alguém que ainda não sabe mexer com Python a trabalhar com dois parceiros dentro do computador: o esquilo, que representa o processador, e o soldado romano, que representa o interpretador Python.

Em vez de só repetir conceitos, vamos resolver pequenas missões. A cada passo, o objetivo é perceber o que cada parceiro faz, como eles se ajudam e como você passa a explorar as capacidades deles para resolver problemas reais.

[PY4E - Python for Everybody](https://www.py4e.com/)

## Ponte rápida para a prática

O começo do livro mistura motivação, arquitetura do computador e a primeira conversa com o Python. Para não deixar o leitor só na teoria, a melhor direção para este resumo é mostrar cedo um resultado concreto: fazer o Python responder na tela.

Se você quiser testar agora, a primeira fala do Python é simples:

```python
print('Hello world')
```

O ponto aqui não é decorar a sintaxe de uma vez. É sentir a ideia central do capítulo: você escreve uma instrução, o interpretador entende e o computador executa.

## Como este tutorial funciona

Pense sempre assim:

1. Você quer resolver um problema.
2. O soldado romano interpreta o que você escreveu.
3. O esquilo executa o trabalho dentro do computador.

A meta não é admirar a teoria de longe. A meta é usar os dois parceiros para guardar informação, pedir respostas, testar ideias e construir soluções simples.
